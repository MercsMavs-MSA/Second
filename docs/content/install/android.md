Android (7+) APK files are available on [GitHub Releases](https://github.com/MercsMavs-MSA/Second/releases/latest).

{{< callout type="warning" >}}
The app only supports tablet sized devices (7" or larger). Phones are not supported.
{{< /callout >}}

## Installation Steps

### 1. Download and open the latest APK from [GitHub Releases](https://github.com/MercsMavs-MSA/Second/releases/latest)

![download.png](/media/android_install/download.png)

### 2. If prompted, allow installation from unknown sources

![open.png](/media/android_install/open.png)

![allow_unknown_sources.png](/media/android_install/allow_unknown_sources.png)

### 3. Follow the prompts to install the app

{{< callout type="info" >}}
You may be asked to run a Google Play Protect scan. This may take a minute.
{{< /callout >}}

![install.png](/media/android_install/install.png)

![installed.png](/media/android_install/installed.png)

### 4. Open the app

Congratulations, _Second_ is now installed. Repeat this process when updating to a newer version.
